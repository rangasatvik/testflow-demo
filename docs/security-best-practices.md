# Security Best Practices

This starter guide supports the MVP security assessment experience. It is intended
for small teams that need practical controls before adopting a full governance,
risk, and compliance platform.

## Identity And Access

- Require MFA for email, finance, source control, admin consoles, and systems
  containing customer data.
- Use separate admin accounts for privileged work.
- Review privileged access quarterly.
- Remove access during employee and contractor offboarding.

## Devices And Endpoints

- Require full-disk encryption on company-managed laptops.
- Enable automatic screen locking.
- Patch operating systems, browsers, and critical apps within 14 days.
- Ensure lost or stolen devices can be remotely locked or wiped.

## Data Protection

- Store sensitive files in approved company systems.
- Avoid keeping customer data in personal drives, inboxes, or unmanaged exports.
- Back up critical data automatically.
- Test restore procedures before an incident.
- Assign owners and retention expectations for vendor-shared data.

## Incident Readiness

- Provide a clear reporting path for phishing, suspicious logins, and lost
  devices.
- Name an incident owner for security triage and customer-impact decisions.
- Keep logs for core business systems.
- Document severity levels, communication owners, and legal contacts.

## Training Modules

- Phishing triage: suspicious links, sender verification, and safe reporting.
- Password and MFA habits: password managers, MFA recovery, and code handling.
- Customer data handling: classification, secure sharing, and retention.
- Incident first response: evidence preservation, escalation, and communication.
